# Overview

API endpoints that relate to video speakers and interviewees.
</br></br>


**Implementation**

`api_speaker.py`.
</br></br>


**Base URL**

/api/speakers
</br></br>


**Endpoint Summary**

| Endpoint                            | Description                                  |
| ----------------------------------- | -------------------------------------------- |
| /                                   | Get all speakers                             |
| /{{speaker_id}}                     | Get one speaker                              |
| /video/{{video_id}}                 | Get speakers on a video                      |
</br></br>
