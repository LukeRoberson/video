# Overview

API endpoints for tag management.
</br></br>


**Implementation**

`api_tag.py`.
</br></br>


**Base URL**

/api/tags
</br></br>


**Endpoint Summary**

| Endpoint                            | Description                                  |
| ----------------------------------- | -------------------------------------------- |
| /                                   | Get all tags                                 |
| /{{tag_id}}                         | Get a tag                                    |
| /video/{{video_id}}                 | Get tags on a video                          |
